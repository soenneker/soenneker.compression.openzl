# ![](https://user-images.githubusercontent.com/4441470/224455560-91ed3ee7-f510-4041-a8d2-3fc093025112.png) Soenneker.Compression.OpenZl
### A dependency-free managed C# implementation of OpenZL compression.

## Installation

```
dotnet add package Soenneker.Compression.OpenZl
```

The file is copied to the output directory, and located at the relative path: `Resources\`.
